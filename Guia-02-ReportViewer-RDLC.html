RptAlumnos.rdlc

La unidad de reportes

Un reporte convierte los datos de la base en un documento que se puede ver, imprimir o guardar. La unidad avanza de lo más manual a lo más automatizado:

1

PrintDocument + PrintPreviewDialog

Para qué sirve: imprimir tickets, constancias o listados simples sin instalar paquetes. Es la base de cualquier herramienta de reportes.

Qué se aprende: dibujar con Graphics, paginar con HasMorePages, vista previa, configuración de página e impresora.

2

ReportViewer Core + RDLC Este tema

Para qué sirve: reportes formales de negocio (listados, facturas, estados de cuenta) que se diseñan visualmente. El motor pagina, agrupa, suma y exporta.

Qué se aprende: diseñar un .rdlc, alimentarlo con un DataTable, agrupar por carrera, calcular totales con expresiones, recibir parámetros y exportar a PDF, Excel o Word.

3

ClosedXML y QuestPDF

Para qué sirve: generar archivos directamente desde un botón “Exportar”, sin abrir un visor.

Qué se aprende: crear un .xlsx con formato desde un DataTable (ClosedXML) y un PDF compuesto por código (QuestPDF).

Cómo funciona un RDLC

En el tema 1 tu código dibujaba cada línea. Aquí el trabajo se divide en dos: un archivo .rdlc describe cómo se ve el reporte, y tu código solo entrega los datos y los parámetros.

PiezaQué esEn este ejercicio

Expresiones

Un valor que empieza con = es una expresión escrita en Visual Basic. El motor la evalúa para cada fila, grupo o página.

ExpresiónDevuelve
=Fields!promedio.ValueEl valor del campo en la fila actual.
=Parameters!pCarrera.ValueEl valor del parámetro enviado por el código.
=CountRows()Cantidad de filas del ámbito actual (el grupo o toda la tabla).
=Avg(Fields!promedio.Value)Promedio del ámbito actual. También existen Sum, Min y Max.
=Globals!PageNumber, Globals!TotalPagesPágina actual y total. Solo en el encabezado o pie de página.
=Globals!ExecutionTimeFecha y hora en que se generó el reporte.
=IIf(condición, sí, no)Valor condicional, por ejemplo el color de un promedio bajo.
Ámbito: la misma expresión =Avg(Fields!promedio.Value) da el promedio de la carrera si está en el pie del grupo, y el promedio general si está en la fila de total, fuera del grupo.

Práctica guiada

Sigue los pasos en orden y marca cada punto de control al comprobarlo. El proyecto de referencia completo está en 02-ReportViewer-RDLC/src.

1. Preparar el proyecto

  1. Base de datos: se usa la misma del tema 1. Si no la tienes, ejecuta 01-PrintDocument/bd/reportes_pae.sql.
  2. Diseñador de informes: en Visual Studio 2026, Extensiones → Administrar extensiones, busca e instala Microsoft RDLC Report Designer 2022+ (versión 18, compatible con VS 2026). Cierra Visual Studio para que termine la instalación.
  3. Crea una Aplicación de Windows Forms (Visual Basic) llamada ReporteRDLC, con .NET 10.0. Elimina Form1.vb y agrega el formulario FrmReporte.vb.
  4. Instala dos paquetes NuGet: MySqlConnector 2.4.0 y ReportViewerCore.WinForms 15.1.33.
  5. Crea la carpeta Reportes en el proyecto y deja el .vbproj así:
ReporteRDLC.vbproj
<Project Sdk="Microsoft.NET.Sdk">

      <SubType>Form</SubType>
    </Compile>
  </ItemGroup>

Por qué se copia el .rdlc: el programa lee el reporte desde bin\Debug\net10.0-windows\Reportes. La regla None Update lo copia ahí en cada compilación.

2. Esquema de datos

El diseñador necesita saber qué campos tendrá el reporte. En proyectos .NET se le indica con un archivo .xsd. Agrega en Reportes un archivo XML llamado DsReportes.xsd con este contenido (también está en el repositorio):

Reportes/DsReportes.xsd
<?xml version="1.0" encoding="utf-8"?>
<!--
  Esquema de datos SOLO para el diseñador de informes.
  Le indica al diseñador qué campos existen. En tiempo de ejecución
  el reporte recibe un DataTable con columnas de los mismos nombres.
-->
<xs:schema id="DsReportes" targetNamespace="http://tempuri.org/DsReportes.xsd"
           xmlns:mstns="http://tempuri.org/DsReportes.xsd"
           xmlns="http://tempuri.org/DsReportes.xsd"
           xmlns:xs="http://www.w3.org/2001/XMLSchema"
           xmlns:msdata="urn:schemas-microsoft-com:xml-msdata"
           attributeFormDefault="qualified" elementFormDefault="qualified">
  <xs:element name="DsReportes" msdata:IsDataSet="true" msdata:UseCurrentLocale="true">
    <xs:complexType>
      <xs:choice minOccurs="0" maxOccurs="unbounded">
        <xs:element name="Alumnos">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="carnet" type="xs:string" minOccurs="0" />
              <xs:element name="nombres" type="xs:string" minOccurs="0" />
              <xs:element name="apellidos" type="xs:string" minOccurs="0" />
              <xs:element name="carrera" type="xs:string" minOccurs="0" />
              <xs:element name="promedio" type="xs:decimal" minOccurs="0" />
            </xs:sequence>
          </xs:complexType>
        </xs:element>
      </xs:choice>
    </xs:complexType>
  </xs:element>
</xs:schema>
Importante: este archivo solo lo usa el diseñador. Al ejecutar, el reporte recibe el DataTable de MariaDB. Por eso los nombres de las columnas del SELECT deben ser idénticos a los del esquema.

    Private Const NOMBRE_DATASET As String = "DsAlumnos"   ' = <DataSet Name> del .rdlc

Región 2. Inicio. Se agrega el visor, se carga el .rdlc una sola vez y se llena el filtro. BringToFront evita que el visor quede debajo del panel.

FrmReporte.vb, región 2
#Region "2. Inicio del formulario"

    Private Sub FrmReporte_Load(sender As Object, e As EventArgs) Handles MyBase.Load
        ' a) Ubicar el visor debajo del panel de filtros
        rvReporte.Dock = DockStyle.Fill
        rvReporte.ShowParameterPrompts = False      ' el parámetro lo envía el código
        Controls.Add(rvReporte)
        rvReporte.BringToFront()                    ' Fill ocupa solo el espacio libre

        ' b) Cargar la definición del reporte (una sola vez)
        If Not File.Exists(rutaRdlc) Then
            MessageBox.Show("No se encontró el reporte:" & vbCrLf & rutaRdlc,
                            "Reporte", MessageBoxButtons.OK, MessageBoxIcon.Error)
            btnGenerar.Enabled = False
            Return
        End If
        Using fs As New FileStream(rutaRdlc, FileMode.Open, FileAccess.Read)
            rvReporte.LocalReport.LoadReportDefinition(fs)
        End Using
        rvReporte.LocalReport.DisplayName = "Listado de alumnos"   ' nombre al exportar

        ' c) Llenar el filtro de carreras
        CargarCarreras()
    End Sub

#End Region

Región 3. Acceso a datos. Si se elige una carrera, la consulta agrega un WHERE con parámetro; con “(Todas)” trae a todos.

FrmReporte.vb, región 3
#Region "3. Acceso a datos"

    Private Sub CargarCarreras()
        cboCarrera.Items.Clear()
        cboCarrera.Items.Add(TODAS)
        Try
            Using cn As MySqlConnection = ObtenerConexion(),
                  cmd As New MySqlCommand("SELECT DISTINCT carrera FROM alumnos ORDER BY carrera", cn)
                cn.Open()
                Using dr As MySqlDataReader = cmd.ExecuteReader()
                    While dr.Read()
                        cboCarrera.Items.Add(dr.GetString(0))
                    End While
                End Using
            End Using
        Catch ex As MySqlException
            MessageBox.Show("Error al consultar MariaDB:" & vbCrLf & ex.Message,
                            "Base de datos", MessageBoxButtons.OK, MessageBoxIcon.Error)
        End Try
        cboCarrera.SelectedIndex = 0
    End Sub

    ' Devuelve los alumnos de una carrera, o de todas
    Private Function ObtenerAlumnos(carrera As String) As DataTable
        Dim filtrar As Boolean = (carrera <> TODAS)
        Dim sql As String = "SELECT carnet, nombres, apellidos, carrera, promedio FROM alumnos"
        If filtrar Then sql &= " WHERE carrera = @carrera"
        sql &= " ORDER BY carrera, apellidos, nombres"

        Dim tabla As New DataTable()
        Using cn As MySqlConnection = ObtenerConexion(),
              da As New MySqlDataAdapter(sql, cn)
            If filtrar Then da.SelectCommand.Parameters.AddWithValue("@carrera", carrera)
            da.Fill(tabla)                       ' el adaptador abre y cierra la conexión
        End Using
        Return tabla
    End Function

#End Region

Región 4. Generar el reporte. Tres pasos: datos, parámetro y RefreshReport. El agrupamiento y los totales ya están en el .rdlc; el código no los calcula.

FrmReporte.vb, región 4
#Region "4. Generar el reporte"

    Private Sub btnGenerar_Click(sender As Object, e As EventArgs) Handles btnGenerar.Click
        Dim carrera As String = cboCarrera.Text
        Dim tabla As DataTable

        Try
            tabla = ObtenerAlumnos(carrera)
        Catch ex As MySqlException
            MessageBox.Show("Error al consultar MariaDB:" & vbCrLf & ex.Message,
                            "Base de datos", MessageBoxButtons.OK, MessageBoxIcon.Error)
            Return
        End Try

        ' a) Datos: el nombre debe coincidir EXACTAMENTE con el DataSet del .rdlc
        rvReporte.LocalReport.DataSources.Clear()
        rvReporte.LocalReport.DataSources.Add(New ReportDataSource(NOMBRE_DATASET, tabla))

        ' b) Parámetro: se muestra en el encabezado del reporte
        rvReporte.LocalReport.SetParameters(New ReportParameter("pCarrera", carrera))

        ' c) Mostrar como se verá impreso y procesar
        rvReporte.SetDisplayMode(DisplayMode.PrintLayout)
        rvReporte.ZoomMode = ZoomMode.PageWidth
        rvReporte.RefreshReport()

        btnGuardarPdf.Enabled = True
    End Sub

#End Region

Región 5. Exportar por código. Render genera el archivo sin pasar por el visor. Con "EXCELOPENXML" o "WORDOPENXML" se obtiene .xlsx o .docx.

FrmReporte.vb, región 5
#Region "5. Exportar a PDF por código"

    ' Además de la barra del visor, el reporte puede exportarse sin abrir menús
    Private Sub btnGuardarPdf_Click(sender As Object, e As EventArgs) Handles btnGuardarPdf.Click
        Using dlg As New SaveFileDialog() With {
                .Filter = "Documento PDF (*.pdf)|*.pdf",
                .FileName = "Listado de alumnos.pdf"}

            If dlg.ShowDialog(Me) <> DialogResult.OK Then Return

            Try
                ' Formatos válidos: "PDF", "EXCELOPENXML", "WORDOPENXML", "IMAGE"...
                Dim bytes As Byte() = rvReporte.LocalReport.Render("PDF")
                File.WriteAllBytes(dlg.FileName, bytes)
                MessageBox.Show("Archivo guardado:" & vbCrLf & dlg.FileName,
                                "Exportar", MessageBoxButtons.OK, MessageBoxIcon.Information)
            Catch ex As Exception
                MessageBox.Show("No se pudo exportar:" & vbCrLf & ex.Message,
                                "Exportar", MessageBoxButtons.OK, MessageBoxIcon.Error)
            End Try
        End Using
    End Sub

#End Region

La unidad de reportes

Un reporte convierte los datos de la base en un documento que se puede ver, imprimir o guardar. La unidad avanza de lo más manual a lo más automatizado:

1

PrintDocument + PrintPreviewDialog

Para qué sirve: imprimir tickets, constancias o listados simples sin instalar paquetes. Es la base de cualquier herramienta de reportes.

Qué se aprende: dibujar con Graphics, paginar con HasMorePages, vista previa, configuración de página e impresora.

2

ReportViewer Core + RDLC

Para qué sirve: reportes formales de negocio que se diseñan visualmente. El motor pagina, agrupa, suma y exporta desde un visor.

Qué se aprende: diseñar un .rdlc, alimentarlo con un DataTable, agrupar, calcular totales con expresiones y recibir parámetros.

3

ClosedXML y QuestPDF Este tema

Para qué sirve: generar archivos listos para enviar (un Excel que el usuario puede filtrar y recalcular, un PDF para imprimir o adjuntar) con un solo clic, sin abrir un visor.

Qué se aprende: crear un .xlsx con formato, fórmulas y formato condicional (ClosedXML), y un PDF compuesto por código con encabezado, tabla y pie (QuestPDF).

ClosedXML

Se trabaja como en Excel: se crea un libro, se agrega una hoja y se escribe en celdas por fila y columna. Los rangos permiten dar formato a muchas celdas de una vez.

InstrucciónQué hace
New XLWorkbook()Crea un libro vacío en memoria.
libro.Worksheets.Add("Alumnos")Agrega una hoja y la devuelve.
hoja.Cell(5, 1).Value = "Carnet"Escribe en la fila 5, columna 1 (A5). También vale hoja.Cell("A5").
hoja.Cell(6, 1).InsertData(tabla)Copia todas las filas del DataTable a partir de A6, sin encabezados.
hoja.Range(5, 1, 5, 5).Style…Formato a un rango: fuente, relleno, bordes, formato numérico.
.FormulaA1 = "AVERAGE(E6:E65)"Escribe una fórmula; Excel la calcula al abrir el archivo.
.AddConditionalFormat().WhenLessThan(75)Formato condicional: Excel lo aplica según el valor.
libro.SaveAs(ruta)Guarda el archivo .xlsx.

QuestPDF

El documento se describe con código: cada página tiene tres zonas y cada zona es un contenedor al que se le encadenan instrucciones. QuestPDF calcula los saltos de página y repite el encabezado de la tabla.

InstrucciónQué hace
Document.Create(...) → .Page(...)Crea el documento y define una página: tamaño, márgenes y estilo de texto.
.Header(), .Content(), .Footer()Zonas de la página. El encabezado y el pie se repiten en cada hoja.
.Row(...), .Column(...)Colocan elementos uno al lado del otro o uno debajo del otro.
.Table(...)Tabla con columnas fijas (ConstantColumn) o proporcionales (RelativeColumn).
.Background(), .Padding(), .Border…(), .AlignRight()Estilo del contenedor.
.Text("…").Bold().FontSize(16).FontColor("#0A3A7A")Texto y su estilo.
.CurrentPageNumber(), .TotalPages()Número de página dentro de un texto.
documento.GeneratePdf(ruta)Calcula las páginas y guarda el archivo.
Sintaxis de VB: QuestPDF recibe lambdas, es decir, bloques de código que se pasan como parámetro: Sub(pagina) … End Sub. QuestPDF los ejecuta cuando arma el documento.
Licencia y fuente: QuestPDF exige declarar la licencia una vez al iniciar (QuestPDF.Settings.License). La fuente predeterminada, Lato, viene incluida en el paquete; desde la versión 2026.9.0 las fuentes instaladas en Windows no se usan de forma predeterminada.

FrmExportar.vb, región 2
#Region "2. Carga de datos"

    Private Sub FrmExportar_Load(sender As Object, e As EventArgs) Handles MyBase.Load
        HabilitarExportar(False)
        CargarCarreras()
    End Sub

    Private Sub CargarCarreras()
        cboCarrera.Items.Clear()
        cboCarrera.Items.Add(TODAS)
        Try
            Using cn As MySqlConnection = ObtenerConexion(),
                  cmd As New MySqlCommand("SELECT DISTINCT carrera FROM alumnos ORDER BY carrera", cn)
                cn.Open()
                Using dr As MySqlDataReader = cmd.ExecuteReader()
                    While dr.Read()
                        cboCarrera.Items.Add(dr.GetString(0))
                    End While
                End Using
            End Using
        Catch ex As MySqlException
            MessageBox.Show("Error al consultar MariaDB:" & vbCrLf & ex.Message,
                            "Base de datos", MessageBoxButtons.OK, MessageBoxIcon.Error)
        End Try
        cboCarrera.SelectedIndex = 0
    End Sub

    Private Sub btnCargar_Click(sender As Object, e As EventArgs) Handles btnCargar.Click
        Dim carrera As String = cboCarrera.Text
        Dim filtrar As Boolean = (carrera <> TODAS)
        Dim sql As String = "SELECT carnet, nombres, apellidos, carrera, promedio FROM alumnos"
        If filtrar Then sql &= " WHERE carrera = @carrera"
        sql &= " ORDER BY apellidos, nombres"

        Try
            Dim tabla As New DataTable()
            Using cn As MySqlConnection = ObtenerConexion(),
                  da As New MySqlDataAdapter(sql, cn)
                If filtrar Then da.SelectCommand.Parameters.AddWithValue("@carrera", carrera)
                da.Fill(tabla)
            End Using

            tablaAlumnos = tabla
            carreraCargada = carrera
            dgvAlumnos.DataSource = tablaAlumnos
            lblEstado.Text = "Registros cargados: " & tablaAlumnos.Rows.Count
            HabilitarExportar(tablaAlumnos.Rows.Count > 0)
        Catch ex As MySqlException
            MessageBox.Show("Error al consultar MariaDB:" & vbCrLf & ex.Message,
                            "Base de datos", MessageBoxButtons.OK, MessageBoxIcon.Error)
        End Try
    End Sub

#End Region

FrmExportar.vb, región 5
#Region "5. Métodos auxiliares"

    ' Muestra "Guardar como" y devuelve la ruta elegida ("" si se cancela)
    Private Function PedirRuta(filtro As String, nombre As String) As String
        Using dlg As New SaveFileDialog() With {.Filter = filtro, .FileName = nombre}
            If dlg.ShowDialog(Me) = DialogResult.OK Then Return dlg.FileName
        End Using
        Return ""
    End Function

    ' Informa el resultado y ofrece abrir el archivo con el programa predeterminado
    Private Sub Terminar(ruta As String)
        lblEstado.Text = "Archivo generado: " & Path.GetFileName(ruta)
        Dim r As DialogResult = MessageBox.Show("Archivo generado:" & vbCrLf & ruta & vbCrLf & vbCrLf &
                                                "¿Deseas abrirlo?", "Exportar",
                                                MessageBoxButtons.YesNo, MessageBoxIcon.Information)
        If r = DialogResult.Yes Then
            Process.Start(New ProcessStartInfo(ruta) With {.UseShellExecute = True})
        End If
    End Sub

    Private Sub HabilitarExportar(valor As Boolean)
        btnExcel.Enabled = valor
        btnPdf.Enabled = valor
    End Sub

#End Region

4. Exportador a Excel

Agrega un módulo ExportadorExcel.vb. Separar la exportación del formulario permite reutilizarla desde cualquier pantalla.

ExportadorExcel.vb
Imports System.IO
Imports ClosedXML.Excel

' Genera un libro de Excel (.xlsx) con el listado de alumnos.
' Usa ClosedXML: no necesita Excel instalado en la computadora.
Module ExportadorExcel

    Private Const FILA_TITULOS As Integer = 5      ' fila donde empieza la tabla
    Private Const AZUL As String = "#0A3A7A"
    Private Const GRIS As String = "#4A5568"
    Private Const BORDE As String = "#D5DCE6"
    Private Const ROJO As String = "#B3261E"

    Public Sub Exportar(tabla As DataTable, carrera As String, ruta As String, rutaLogo As String)
        Using libro As New XLWorkbook()
            Dim hoja As IXLWorksheet = libro.Worksheets.Add("Alumnos")

            ' 1) Encabezado del documento: logo en A1, textos en la columna B
            If File.Exists(rutaLogo) Then
                hoja.AddPicture(rutaLogo).MoveTo(hoja.Cell("A1")).WithSize(84, 48)
            End If
            hoja.Cell("B1").Value = "Universidad Nacional de Ingeniería"
            hoja.Cell("B2").Value = "Listado de alumnos"
            hoja.Cell("B3").Value = "Carrera: " & carrera & "    Generado: " & Date.Now.ToString("dd/MM/yyyy HH:mm")
            hoja.Cell("B1").Style.Font.FontColor = XLColor.FromHtml(GRIS)
            hoja.Cell("B2").Style.Font.SetBold().Font.SetFontSize(16).Font.SetFontColor(XLColor.FromHtml(AZUL))
            hoja.Cell("B3").Style.Font.FontColor = XLColor.FromHtml(GRIS)

            ' 2) Títulos de columna
            Dim titulos() As String = {"Carnet", "Nombres", "Apellidos", "Carrera", "Promedio"}
            For c As Integer = 0 To titulos.Length - 1
                hoja.Cell(FILA_TITULOS, c + 1).Value = titulos(c)
            Next

            ' 3) Datos: InsertData copia todas las filas del DataTable (sin encabezados)
            hoja.Cell(FILA_TITULOS + 1, 1).InsertData(tabla)
            Dim primera As Integer = FILA_TITULOS + 1
            Dim ultima As Integer = FILA_TITULOS + tabla.Rows.Count
            Dim filaTotal As Integer = ultima + 2

            ' 4) Formato de la tabla
            Dim rTitulos As IXLRange = hoja.Range(FILA_TITULOS, 1, FILA_TITULOS, 5)
            rTitulos.Style.Font.Bold = True
            rTitulos.Style.Font.FontColor = XLColor.White
            rTitulos.Style.Fill.BackgroundColor = XLColor.FromHtml(AZUL)

            Dim rTabla As IXLRange = hoja.Range(FILA_TITULOS, 1, ultima, 5)
            rTabla.Style.Border.OutsideBorder = XLBorderStyleValues.Thin
            rTabla.Style.Border.InsideBorder = XLBorderStyleValues.Thin
            rTabla.Style.Border.OutsideBorderColor = XLColor.FromHtml(BORDE)
            rTabla.Style.Border.InsideBorderColor = XLColor.FromHtml(BORDE)
            rTabla.SetAutoFilter()                          ' flechas de filtro en los títulos

            Dim rPromedios As IXLRange = hoja.Range(primera, 5, ultima, 5)
            rPromedios.Style.NumberFormat.Format = "0.00"
            rPromedios.AddConditionalFormat().WhenLessThan(75).Font.SetFontColor(XLColor.FromHtml(ROJO))

            ' 5) Totales con fórmulas: Excel los recalcula si se editan los datos
            hoja.Cell(filaTotal, 1).Value = "Total de alumnos:"
            hoja.Cell(filaTotal, 2).FormulaA1 = $"COUNTA(A{primera}:A{ultima})"
            hoja.Cell(filaTotal, 4).Value = "Promedio general:"
            hoja.Cell(filaTotal, 4).Style.Alignment.Horizontal = XLAlignmentHorizontalValues.Right
            hoja.Cell(filaTotal, 5).FormulaA1 = $"AVERAGE(E{primera}:E{ultima})"
            hoja.Cell(filaTotal, 5).Style.NumberFormat.Format = "0.00"
            hoja.Range(filaTotal, 1, filaTotal, 5).Style.Font.SetBold().Font.SetFontColor(XLColor.FromHtml(AZUL))

            ' 6) Ajustes finales y guardar
            hoja.Columns(1, 5).AdjustToContents(FILA_TITULOS, filaTotal)
            hoja.SheetView.FreezeRows(FILA_TITULOS)         ' los títulos quedan fijos al desplazarse
            hoja.PageSetup.FitToPages(1, 0)                 ' al imprimir: 1 página de ancho
            libro.SaveAs(ruta)
        End Using
    End Sub

End Module
Fórmulas en lugar de valores: el total y el promedio se escriben como COUNTA y AVERAGE. Si el usuario corrige una nota en Excel, el promedio se actualiza solo.

5. Exportador a PDF

Agrega un módulo ExportadorPdf.vb. Exportar define la página y delega cada zona a un método.

ExportadorPdf.vb
Imports System.IO
Imports QuestPDF.Fluent
Imports QuestPDF.Helpers
Imports QuestPDF.Infrastructure

' Genera un PDF con el listado de alumnos.
' Usa QuestPDF: el documento se describe con código (encabezado, contenido y pie).
Module ExportadorPdf

    Private Const AZUL As String = "#0A3A7A"
    Private Const GRIS As String = "#4A5568"
    Private Const TINTA As String = "#16233A"
    Private Const BORDE As String = "#D5DCE6"
    Private Const ALTERNO As String = "#F4F7FB"
    Private Const ROJO As String = "#B3261E"

    Public Sub Exportar(tabla As DataTable, carrera As String, ruta As String, rutaLogo As String)
        Dim documento = Document.Create(
            Sub(contenedor)
                contenedor.Page(
                    Sub(pagina)
                        pagina.Size(PageSizes.Letter)
                        pagina.Margin(1.5F, Unit.Centimetre)
                        pagina.DefaultTextStyle(Function(estilo) estilo.FontSize(9).FontColor(TINTA))

                        pagina.Header().Element(Sub(c) ComponerEncabezado(c, carrera, rutaLogo))
                        pagina.Content().PaddingVertical(10).Element(Sub(c) ComponerTabla(c, tabla))
                        pagina.Footer().Element(Sub(c) ComponerPie(c))
                    End Sub)
            End Sub)

        documento.GeneratePdf(ruta)
    End Sub

    ' Logo + textos, con una línea azul debajo
    Private Sub ComponerEncabezado(c As IContainer, carrera As String, rutaLogo As String)
        c.BorderBottom(1.5F).BorderColor(AZUL).PaddingBottom(6).Row(
            Sub(fila)
                fila.Spacing(12)
                If File.Exists(rutaLogo) Then
                    fila.ConstantItem(70).Height(40).Image(rutaLogo).FitArea()
                End If
                fila.RelativeItem().Column(
                    Sub(col)
                        col.Item().Text("Universidad Nacional de Ingeniería").FontSize(8).FontColor(GRIS)
                        col.Item().Text("Listado de alumnos").FontSize(16).Bold().FontColor(AZUL)
                        col.Item().Text("Carrera: " & carrera & "    Generado: " &
                                        Date.Now.ToString("dd/MM/yyyy HH:mm")).FontSize(8).FontColor(GRIS)
                    End Sub)
            End Sub)
    End Sub

    ' Tabla de alumnos: el encabezado se repite en cada página automáticamente
    Private Sub ComponerTabla(c As IContainer, tabla As DataTable)
        c.Table(
            Sub(t)
                t.ColumnsDefinition(
                    Sub(columnas)
                        columnas.ConstantColumn(75)     ' Carnet
                        columnas.RelativeColumn(2)      ' Nombres
                        columnas.RelativeColumn(2)      ' Apellidos
                        columnas.RelativeColumn(2.4F)   ' Carrera
                        columnas.ConstantColumn(55)     ' Promedio
                    End Sub)

                t.Header(
                    Sub(encabezado)
                        For Each titulo As String In {"Carnet", "Nombres", "Apellidos", "Carrera"}
                            encabezado.Cell().Background(AZUL).Padding(4).Text(titulo).Bold().FontColor(Colors.White)
                        Next
                        encabezado.Cell().Background(AZUL).Padding(4).AlignRight().Text("Promedio").Bold().FontColor(Colors.White)
                    End Sub)

                Dim i As Integer = 0
                For Each fila As DataRow In tabla.Rows
                    Dim fondo As String = If(i Mod 2 = 1, ALTERNO, "#FFFFFF")
                    Dim promedio As Decimal = CDec(fila("promedio"))

                    Celda(t.Cell(), fondo).Text(fila("carnet").ToString())
                    Celda(t.Cell(), fondo).Text(fila("nombres").ToString())
                    Celda(t.Cell(), fondo).Text(fila("apellidos").ToString())
                    Celda(t.Cell(), fondo).Text(fila("carrera").ToString())
                    Celda(t.Cell(), fondo).AlignRight().Text(promedio.ToString("0.00")) _
                        .FontColor(If(promedio < 75D, ROJO, TINTA))
                    i += 1
                Next

                ' Fila de total: 4 columnas combinadas + promedio general
                Dim promedioGeneral As Decimal = CDec(tabla.Compute("AVG(promedio)", ""))
                t.Cell().ColumnSpan(4).BorderTop(1.5F).BorderColor(AZUL).PaddingVertical(4).AlignRight() _
                    .Text($"Total: {tabla.Rows.Count} alumnos    Promedio general:").Bold().FontColor(AZUL)
                t.Cell().BorderTop(1.5F).BorderColor(AZUL).Padding(4).AlignRight() _
                    .Text(promedioGeneral.ToString("0.00")).Bold().FontColor(AZUL)
            End Sub)
    End Sub

    ' Estilo común de las celdas de detalle
    Private Function Celda(c As IContainer, fondo As String) As IContainer
        Return c.Background(fondo).BorderBottom(0.5F).BorderColor(BORDE).PaddingVertical(3).PaddingHorizontal(4)
    End Function

    ' Nombre del curso a la izquierda; "Página N de M" a la derecha
    Private Sub ComponerPie(c As IContainer)
        c.BorderTop(0.5F).BorderColor(BORDE).PaddingTop(4).Row(
            Sub(fila)
                fila.RelativeItem().Text("Programación de Aplicaciones de Escritorio").FontSize(8).FontColor(GRIS)
                fila.RelativeItem().AlignRight().Text(
                    Sub(texto)
                        texto.DefaultTextStyle(Function(estilo) estilo.FontSize(8).FontColor(GRIS))
                        texto.Span("Página ")
                        texto.CurrentPageNumber()
                        texto.Span(" de ")
                        texto.TotalPages()
                    End Sub)
            End Sub)
    End Sub

End Module
Colores: se pasan como texto hexadecimal ("#0A3A7A"); QuestPDF los convierte solo. El fondo alterno se elige con i Mod 2, igual que en el tema 1.

FrmExportar.vb, región 3
#Region "3. Exportar a Excel (ClosedXML)"

    Private Sub btnExcel_Click(sender As Object, e As EventArgs) Handles btnExcel.Click
        Dim ruta As String = PedirRuta("Libro de Excel (*.xlsx)|*.xlsx", "Alumnos.xlsx")
        If ruta = "" Then Return

        Try
            ExportadorExcel.Exportar(tablaAlumnos, carreraCargada, ruta, rutaLogo)
            Terminar(ruta)
        Catch ex As IOException
            ' El caso más común: el archivo sigue abierto en Excel

            MessageBox.Show("Error al generar el archivo:" & vbCrLf & ex.Message, "Exportar a Excel",
                            MessageBoxButtons.OK, MessageBoxIcon.Error)
        End Try
    End Sub
